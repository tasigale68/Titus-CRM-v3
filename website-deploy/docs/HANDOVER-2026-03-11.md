## Architecture

```
www.titus-crm.com
├── / → index.html (marketing site)
├── /agreement-builder → agreement-builder.html
├── /administrator → administrator.html (password: [stored in ADMIN_PASSWORD env secret])
└── email handler → Cloudflare Email Worker

Edge Function: agreement-api (octdvaicofjmaetgfect)
├── POST /waitlist → create lead + auto-tag
├── POST /admin/login → auth token
├── GET /admin/leads → list all leads
├── PATCH /admin/leads/:id → update lead + trigger automation email
├── GET /admin/emails → list admin emails
├── POST /admin/email/send → send email via Resend
├── POST /admin/email/inbound → webhook from CF Worker
├── GET /support-items → NDIS support items
├── POST /agreements/public → create agreement
└── GET /agreements/download/:id → download PDF
```
